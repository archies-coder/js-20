# JS-20: Depth-First JavaScript Interview Prep

Goal: Become a top-tier, all-round JS engineer ready for FAANG+ interviews by mastering fundamentals, internals, and system-level skills. Depth over breadth. Small, focused tasks that compound.

Focus mix for entire repo:

- 90% JavaScript
- 7.5% CSS
- 2.5% HTML

How to use

- Start at `level-01` and progress sequentially. Each level has sub-levels.
- Prefer depth-first: finish all sub-levels within a level before moving on.
- Each sub-level is a small, focused challenge or task.
- Use tests/benchmarks/notes to verify understanding.
- Build a "second brain": document insights in each level’s `NOTES.md`.

TypeScript progression

- Levels 01–08 are pure JS. From Level 09 onward, the repo is TS-first for new code. See `TYPESCRIPT.md` for the staged roadmap and practices.

What you’ll gain

- Deep JS fundamentals (runtime, types, async, memory, perf, design patterns)
- The ecosystem skills used at Amazon/Google/Meta/Atlassian/Spotify/Netflix
- Ability to design/implement/debug production-grade code with clarity & rigor

Structure per level

- `README.md`: challenges + acceptance criteria
- `tasks/`: minimal scoped tasks (one or more)
- `tests/`: unit tests and/or benchmarks
- `NOTES.md`: your write-ups, gotchas, learnings

Tips

- Favor writing tiny, complete programs that prove concepts
- Argue with yourself in `NOTES.md`—why, tradeoffs, counterexamples
- Always benchmark when performance is mentioned
- Practice explaining each topic aloud in under 2 minutes
